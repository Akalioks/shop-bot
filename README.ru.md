# ShopApp: магазин внутри Telegram (Mini App)

Интернет-магазин, который открывается прямо в Telegram: каталог, корзина, оформление заказа и оплата картой. Ничего не нужно устанавливать. Владелец получает заказы в чат и меняет их статусы кнопками, а цены и наличие правит во вкладке **Admin** внутри магазина.

Демо сделано для вымышленного магазина товаров для дома **Nordic Home**. Каталог лежит в `catalog.json`.

## Что умеет

**Покупатель**
- Открывает магазин кнопкой в чате или синей кнопкой **Shop** рядом с полем ввода.
- Видит каталог с категориями и поиском. Карточка товара открывает описание.
- Корзина запоминается, даже если закрыть магазин.
- Выбирает доставку: курьер, почтомат или самовывоз. Бесплатная доставка от €50 считается автоматически, и магазин подсказывает: «add €18 more for free delivery».
- Имя и телефон запоминаются для следующих заказов.
- Платит **картой внутри Telegram** (если подключена оплата) или **при получении**.
- Во вкладке «My orders» видит свои заказы и их статусы. Изменения статуса приходят в чат.
- Внешний вид подстраивается под светлую или тёмную тему Telegram пользователя.

**Владелец**
- Получает в чат каждый заказ с составом, суммой, контактами и адресом.
- Кнопками **📦 Mark shipped**, **✅ Mark delivered** и **❌ Cancel** меняет статус, и покупатель сразу получает уведомление.
- Команда `/admin` показывает продажи за сегодня и за 7 дней, а также открытые заказы.
- Вкладка **Admin** в магазине позволяет менять цену и наличие товара, и покупатели видят изменения сразу.

**Безопасность** (это важно объяснять клиентам)
- Каждый запрос магазина подписан Telegram, и сервер проверяет подпись ключом бота. Поэтому подделать пользователя или чужой заказ нельзя.
- **Цены считает сервер.** Цена, присланная браузером, игнорируется, поэтому «купить за €0.01» не получится.
- Перед списанием денег бот повторно сверяет заказ и сумму (pre-checkout). Оплатить заказ дважды нельзя.
- Уведомления отправляются в фоне, и покупатель не ждёт ответа Telegram при оформлении.

## Демо-режим

`DEMO_MODE=true`: любой может отправить `/admin` и увидеть сторону владельца, но **только со своими** тестовыми заказами. После заказа он получает карточку «как у владельца» с рабочими кнопками статусов. Вкладка Admin в магазине показывается, но только для чтения.

## Оплата картой

Telegram разрешает платить звёздами (Stars) только за цифровые товары. Физические товары оплачиваются через платёжного провайдера, например Stripe.

1. В @BotFather выберите бота, затем **Payments** → **Stripe** → **Connect Stripe TEST**.
2. Скопируйте токен в `PAYMENT_PROVIDER_TOKEN` в `.env`.
3. Для теста используйте карту `4242 4242 4242 4242`, любой будущий срок и любой CVC. Деньги не списываются.

Без токена магазин работает в режиме «оплата при получении».

## Запуск

### Посмотреть магазин в браузере (без Telegram)

```powershell
.venv\Scripts\python dev_server.py
```

Откройте http://localhost:8080/app/. Вы войдёте как владелец, сообщения в Telegram пропускаются, а данные пишутся в отдельную базу `dev.db`. Так удобно править дизайн.

### Полный запуск с ботом

Telegram открывает Mini App **только по HTTPS**, поэтому полноценно магазин заработает после размещения на сервере.

1. Создайте нового бота в @BotFather.
2. Выполните (PowerShell):

```powershell
python -m venv .venv
```
```powershell
.venv\Scripts\pip install -r requirements.txt
```
```powershell
copy .env.example .env
```

3. В `.env` заполните `BOT_TOKEN`, `ADMIN_IDS` и `WEBAPP_URL`. Последнее — это публичный адрес вида `https://ваш-домен/app/`.
4. Запустите:

```powershell
.venv\Scripts\python -m bot
```

Одна программа запускает и бота, и веб-сервер на порту 8080. Сервер (VPS, Railway, Render) должен отдавать порт 8080 по HTTPS.

> `DEV_MODE=true` нужен только для проверки на своём компьютере. На сервере он должен быть `false`, иначе проверка подписи Telegram отключается для локальных запросов.

## Тесты

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
```
```powershell
.venv\Scripts\python -m pytest
```

24 теста. Что они проверяют:
- расчёт суммы и бесплатной доставки, отказ в чужих ценах, проверку наличия и количества;
- API с настоящей подписью Telegram: поддельная, просроченная или изменённая подпись отклоняется;
- заказ с оплатой при получении и с оплатой картой, правильную сумму счёта;
- проверку перед оплатой, защиту от двойной оплаты;
- смену статусов и уведомления, доступ владельца и демо-посетителя.

## Структура

```
bot/
  __main__.py      запуск бота и веб-сервера вместе
  config.py        настройки из .env
  db.py            таблицы: products, orders, order_items
  repo.py          запросы к базе, загрузка catalog.json
  pricing.py       расчёт заказа (чистая логика)
  web.py           API для магазина + проверка подписи Telegram
  notify.py        сообщения покупателю и владельцу
  texts.py         тексты
  keyboards.py     кнопки
  handlers/
    shop.py        /start, /orders, оплата
    owner.py       /admin, статусы заказов
webapp/            страница магазина: index.html, styles.css, app.js (без сборки)
catalog.json       товары, категории, варианты доставки
dev_server.py      предпросмотр в браузере без Telegram
tests/
```
